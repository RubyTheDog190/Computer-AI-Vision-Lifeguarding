# AI Powered Swimming Risk Detection

Using YOLOv5 and PyQt5，this project implements pool participant behavior detection and drowning risk early warning. The interface supports image, video, and camera input, displays detection frames, risk status, event logs, and provides local user management functions.

> This project is for scientific research, teaching, and auxiliary monitoring only, and cannot replace a lifeguard's on-site judgment and response.

## Contents
- `pool_risk_gui.py`：Latest version of the interface and risk warning program.
- `runs/train/exp/weights/best.pt`：Weights of the currently trained three-class classification model.
- `train.py`、`val.py`、`detect.py`：Training, verification, and command-line entry points.
- `models/`、`utils/`：YOLOv5 network and utility code.
- `data/mydata.yaml`：Swimming pool three-class dataset configuration example.
- `yolov5s.pt`：YOLOv5s pre-trained weights, can be used for retraining.

Large-scale datasets, training caches, logs, user databases, and interface outputs are not included in the repository. The full dataset should be organized locally according to the "Dataset Directory" section.

## Environment Installation

Python 3.8–3.10 is recommended. The CUDA version must match the installed PyTorch version.

```bash
python -m venv .venv
```

Windows PowerShell：

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

If using an NVIDIA GPU, please install the corresponding version of torch and torchvision from official PyTorch channels based on your local CUDA environment.

## Launching the Graphical Interface

```bash
python pool_risk_gui.py
```

The program loads by default:

```text
runs/train/exp/weights/best.pt
```

Upon first launch, a local user database will be created automatically with the following initial credentials:

```text
Username：admin
Password：Admin@123
```

Please change the default password immediately after logging in for the first time. You can also start the interface on Windows using start_pool_alert.bat; this script looks for a Conda environment named env_yolov5 by default.

Common starup parameters:

```bash
python pool_risk_gui.py --device 0 --imgsz 640 --conf 0.25 --iou 0.45
python pool_risk_gui.py --device cpu
```

## Dataset Directory

Datasets are not committed to GitHub. Please create the following structure in the repository root directory:

```text
datasets/
└─ pool/
   ├─ images/
   │  ├─ train/
   │  ├─ val/
   │  └─ test/
   └─ labels/
      ├─ train/
      ├─ val/
      └─ test/
```

Each image corresponds to a .txt label file of the same name, with the class index order:

```text
0 swimming
1 tread water
2 drowning
```

## Training and Validation

```bash
python train.py --weights yolov5s.pt --cfg models/yolov5s.yaml --data data/mydata.yaml --img 640 --batch-size 16 --epochs 100
python val.py --weights runs/train/exp/weights/best.pt --data data/mydata.yaml --img 640
```

The contents of runs/ generated by training are ignored by default; the repository only retains best.pt used by default by the current GUI.
